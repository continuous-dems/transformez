# API Reference


Reference documentation for Transformez's Python API. This section is generated from the source docstrings and covers the public interfaces of the stable 1.x API.

The transformation entry points live in the [`transformez.api`](api.md) module; the [`ShiftGrid`](api.md) object and the typed reference models (`ParsedReference`, `VerticalReference`) are the supporting types most likely to appear in user code. Internals outside these pages — the engine, planner, and resolver modules — are not yet considered stable and may change between minor releases.

Start with the [Developer API](api.md) page, or see the [Usage guide](/user_guide/usage.md) for worked examples rather than raw signatures.
